Проверка ярлыка NodeService

Эти варианты отличаются настройкой системной строки iPhone. Открытие в обычной вкладке ничего не покажет: каждый вариант нужно добавить на экран «Домой» отдельным ярлыком.

Старый ярлык панели не обновляет сохранённые параметры. Для чистой проверки создайте новые ярлыки по ссылкам ниже.
  1. Откройте вариант.
  2. Нажмите «Поделиться» → «На экран Домой».
  3. Запустите созданный ярлык и откройте/закройте меню.
